# Calendar Engine – Production Planning

## Regler

- Leverans senast 13:00 ska produceras dagen innan.
- Leverans utanför stadsgränsen ska produceras dagen innan.
- Leverans utanför stadsgränsen ska även planera budhämtning tidig morgon.

## Kalenderaktiviteter

När en order skapas ska FOS kunna skapa:

1. Produktion
2. Budhämtning
3. Kundleverans

## Syfte

Floristen ska inte bara se leveransdagen, utan även vad som måste produceras dagen innan.
