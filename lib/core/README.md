# FloristOS Core

Denna katalog innehåller FloristOS återanvändbara kärnmotorer.

Regler:

1. Core får inte vara beroende av en enskild sida.
2. Core får inte innehålla UI-komponenter.
3. Core ska kunna användas av flera applikationer.
4. Externa leverantörer ska anslutas via adapters eller plugins.
5. Företagsdata ska utgå från Company Passport.
6. Landsspecifika regler ska utgå från Country Engine.
7. Privata NFOS-strategier får inte exponeras publikt.
