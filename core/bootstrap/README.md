# FOS Bootstrap

## Syfte

FOS Bootstrap är den centrala startpunkten för FloristSocial Operating System.

## Ansvar

- Registrera Engines
- Registrera Subscribers
- Visa FOS Health
- Ge Development Center en gemensam källa för Engine-status
- Hålla Bootstrap fritt från affärslogik

## Viktig princip

Bootstrap kopplar ihop FOS, men innehåller inte affärslogik.
