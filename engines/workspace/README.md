# Workspace Engine

## Syfte

Workspace Engine ansvarar för FOS Arbetsyta.

Arbetsytan är användarens startsida och ska visa det viktigaste för dagen utan att användaren behöver leta.

---

## Ansvar

- Morning Briefing
- Workspace Cards
- Widgets
- Rollstyrd arbetsyta
- Prioritering av viktiga händelser
- Sammanfattning från andra Engines

---

## Viktig princip

Arbetsytan ska inte innehålla affärslogik.

Den ska presentera data från andra Engines:

- Calendar Engine
- Order Engine
- CRM / Relationship Engine
- Trust Engine
- Economy Engine
- Intelligence Engine
- Notification Engine

---

## Mål

FOS Arbetsyta ska hjälpa användaren att snabbt förstå:

- Vad händer idag?
- Vad kräver åtgärd?
- Vad är viktigast just nu?
- Vad rekommenderar FOS?
