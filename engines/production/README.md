# Production Engine

## Syfte

Production Engine ansvarar för allt som sker från att en order är mottagen tills produkten är klar för hämtning eller leverans.

## Ansvar

- Produktionsplanering
- Produktionskö
- Produktionstid
- Packningstid
- Kvalitetskontroll
- Kapacitet
- Status för produktion

## Relation till andra Engines

- Workflow Engine bestämmer vilka steg som ska ske.
- Calendar Engine bestämmer när aktiviteter sker.
- Workspace Engine visar nästa steg och dagens arbetskö.
- Trust Engine används efter leverans, inte under produktion.

## Grundregel

Produktionens starttid ska utgå från floristens arbetsstart, ofta 10:00, inte från leveranstiden ensam.
